## Boundaries and discovered gaps

Inference supplies observations; AutonomousExecutionController decides/executes, TaskBoard records progress, and Execution Supervisor enforces lifecycle. The deterministic tool runner remains the only admitted execution boundary. External Codex owns its inner loop.

The baseline contains framework messages/tools/callbacks, two capability registries, maintained model tables and name heuristics, permissive unknown profiles, deterministic routing winner selection, lossy structured/plain retries, pickle-based FAISS storage, and embedding-required model settings. These are source observations, not runtime diagnoses. No baseline tests or benchmarks were run.

Repository vector retrieval is explicitly retired. Independent external memory search and media inference remain supported. Existing analysis chunks and symbols remain local metadata.
