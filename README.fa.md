## اگر هوش مصنوعی شما می‌توانست فراتر از پاسخ دادن عمل کند چه می‌شد؟

بیشتر ابزارهای هوش مصنوعی در پاسخ دادن متوقف می‌شوند.

شما پرسشی مطرح می‌کنید، آن‌ها پاسخی تولید می‌کنند و سپس خودتان باید تصمیم بگیرید چه کار کنید.

**Mana-Agent برای آنچه پس از پاسخ رخ می‌دهد ساخته شده است.**

می‌تواند اهداف شما را درک کند، محیط را بررسی کند، برای اقدامات برنامه بریزد، عامل‌های تخصصی را هماهنگ کند، از ابزارهای واقعی استفاده کند و نتایج را بررسی کند.

نه فقط برای نوشتن کد.

بلکه برای پژوهش، ساخت، اشکال‌زدایی، مدیریت، خودکارسازی و حل وظایف پیچیده در سیستم‌های متصل.

**شما مقصد را تعیین می‌کنید؛ Mana-Agent به پیمودن مسیر کمک می‌کند.**

## آشنایی با Mana-Agent

Mana-Agent یک پلتفرم متن‌باز مبتنی بر پایتون برای هماهنگ‌سازی عامل‌های هوش مصنوعی است که حلقهٔ اجرای خودمختار، عامل‌های تخصصی، مدیریت پایدار وظایف، اجرای نظارت‌شدهٔ ابزارها و یکپارچه‌سازی‌های توسعه‌پذیر را ترکیب می‌کند.

این پلتفرم قابلیت‌های متعددی را در یک محیط هماهنگ گرد هم می‌آورد:

- **درک:** بررسی مخازن، اسناد، APIها و شواهد موجود پیش از اقدام.
- **تصمیم‌گیری:** انتخاب مدل‌ها، عامل‌ها، ابزارها و راهبردهای اجرایی مناسب.
- **اجرا:** استفاده از ابزارهای برنامه‌نویسی، خودکارسازی مرورگر، سرویس‌های خارجی و سیستم‌های متصل.
- **هماهنگی:** تقسیم کار میان عامل‌های تخصصی و پیگیری وابستگی‌ها و پیشرفت.
- **یادآوری:** استفادهٔ دوباره از زمینه، تصمیم‌ها و آموخته‌های مجاز در وظایف مرتبط.
- **بررسی:** ارزیابی نتایج واقعی به‌جای تلقی پایان اجرای ابزار به‌عنوان موفقیت.
- **ادامه:** بازنگری برنامه، بازیابی یا درخواست مداخلهٔ انسانی هنگامی که هدف هنوز محقق نشده است.

هدف ساده است:

**هوش مصنوعی نه‌تنها برای اندیشیدن به کار، بلکه برای رساندن آن به نتیجه‌ای قابل اعتماد مفید باشد.**

<a name="what-can-mana-agent-do"></a>
## Mana-Agent چه کارهایی می‌تواند انجام دهد؟

| چالش شما | Mana-Agent چگونه می‌تواند کمک کند |
|---|---|
| «این کدبیس را نمی‌فهمم.» | بررسی معماری، وابستگی‌ها، جریان‌های اجرا و فایل‌های مرتبط. |
| «چیزی خراب شده است.» | بررسی نشانه‌ها، شناسایی علت‌های احتمالی، پیشنهاد راه‌حل و اجرای بررسی‌ها. |
| «می‌خواهم چیزی پیچیده بسازم.» | تقسیم اهداف، هماهنگی عامل‌های برنامه‌نویسی، مدیریت وابستگی‌ها و بازبینی پیاده‌سازی. |
| «این کار مراحل زیادی دارد.» | پیگیری پیشرفت با حلقهٔ خودمختار، TaskBoard و ناظر اجرا. |
| «به اطلاعاتی از یک API نیاز دارم.» | بررسی مستندات API، اعتبارسنجی درخواست‌ها و اجرای عملیات پشتیبانی‌شده. |
| «این روند کاری را مدام تکرار می‌کنم.» | ساخت خودکارسازی یا آموزش اقدامات تکرارپذیر با Teach Mode. |
| «می‌خواهم هوش مصنوعی با ابزارهای مختلف کار کند.» | یکپارچه‌سازی مرورگر، Git، SSH، ایمیل، تلگرام، پروتکل‌ها و سرویس‌های خارجی. |
| «در طول اجرا چه اتفاقی افتاد؟» | بررسی فعالیت‌ها، ابزارها، تصمیم‌ها، خطاها، نقاط بازیابی و خروجی‌ها. |

### یک رابط؛ انواع گوناگون کار

```text
> نحوهٔ کار احراز هویت در این مخزن را توضیح بده.

> علت شکست آخرین استقرار را پیدا کن.

> یک قابلیت جدید را برنامه‌ریزی و پیاده‌سازی کن، سپس تست‌های آن را اجرا کن.

> این مستندات API را بخوان و کمک کن endpoint مناسب را فراخوانی کنم.

> این فایل‌ها را تحلیل کن و گزارشی کاربردی تهیه کن.

> این پروژه را به وظایف مستقل تقسیم کن و پیشرفت را پیگیری کن.

> پیش از تلاش دوباره برای این عملیات، اشتباهات قبلی را بررسی کن.
```

Mana-Agent برای پشتیبانی از پرسش‌های متمرکز و همچنین روندهای کاری چندمرحله‌ای طراحی شده است.

## شروع سریع

### ۱. نصب

به Python 3.10–3.14 نیاز دارد.

روش پیشنهادی نصب با pipx:

```bash
pipx install git+https://github.com/manaplatform/mana-agent.git
```

یا مستقیماً از مخزن نصب کنید:

```bash
git clone https://github.com/manaplatform/mana-agent.git
cd mana-agent

python3 -m venv .venv
source .venv/bin/activate

python -m pip install -e .
```

### ۲. پیکربندی

```bash
mana-agent --configure
```

ارائه‌دهندهٔ مدل، اطلاعات احراز هویت، ترجیحات مدل و قابلیت‌های پشتیبانی‌شده را تنظیم کنید.

### ۳. شروع

```bash
cd /path/to/your/project
mana-agent
```

آماده‌اید.

با پرسشی دربارهٔ مخزن خود شروع کنید، درخواست بررسی بدهید یا کاری را که می‌خواهید انجام دهید شرح دهید.

**اولین وظیفهٔ شما لازم نیست پیچیده باشد.**

برای نمونه:

```text
این پروژه را تحلیل کن و معماری، اجزای اصلی،
وابستگی‌ها و خطرهای احتمالی آن را توضیح بده.
```

### ۴. بررسی داشبورد

```bash
mana-agent dashboard --root-dir .
```

داشبورد اختیاری راه دیگری برای تعامل با Mana-Agent، بررسی فعالیت‌ها و مدیریت روندهای کاری فراهم می‌کند.
